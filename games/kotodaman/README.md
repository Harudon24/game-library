# コトダマン

`index.html` → `owned-characters.html` の2階層。画像を使わず、`owned-characters.json` を表示する静的ページです。進化素材は掲載しません。

## 新規キャラの追加

1. `owned-characters.json` の `characters` に1件追加します。名前だけが分かる場合は依頼時に名前を伝え、同名版がある場合は属性・衣装名で区別します。
2. `id` は重複しない固定値。現在は参考ページのIDを使用。`name`, `element`, `species` を記入し、`letter`, `rarity`, `unevolved` は未確認なら `null`。`reference_url` も省略またはnullにできます。画像の項目・画像ファイルは不要です。
3. `updated` を更新日に変更し、コミットします。件数は自動計算します。UIでの入力は検索条件のみで、ブラウザ内だけに所持状態を保存する仕組みはありません。

`unevolved: true` は登録画像に「未進化」表示あり、falseは表示なし、nullは未確認です。falseを進化済みと断定しないでください。文字は登録画面の代表1文字で、利用可能な全ての文字ではありません。Lv・福は未転記のため表示していません。

データ出典：2026-09-14に提供された所持画像。キャラ名は各レコードのGameWith参照先と照合。876種で開始しています。元スクリーンショットはリポジトリに含めません。
