素材集め
ロードマップ

序盤からレベル帯ごとに、何を使って素材を集めると楽になるかを整理。恐竜だけでなく、道具や手拾いなどの方法も含めています。

Lv1 → 69+恐竜 + 道具Astraeos向け

素材別おすすめ一覧

レベル帯ごとに次の手段へ乗り換える
素材Lv1–19Lv20–35Lv36–60Lv61+恐竜以外 / 補足
木材石の斧。モスコプスがいれば補助。金属の斧 → ステゴ Lv26 → マンモス Lv31マンモスを継続。木材重量75%軽減。カストロイデス Lv61 / テリジノ Lv69。運搬込みならマンモスも強い。斧系が木材向け。現在はマンモス主力でOK。
わら石のピッケル。トリケラ Lv16も大量に取れる。金属のピッケル / マンモス Lv31。マンモスで木材と同時回収。ブロント Lv63で大量回収。マンモスでも十分。ピッケル系で木を叩くと木材よりわら寄り。
繊維手摘み / モスコプス。金属の鎌 Lv30。金属の鎌を継続。採取量が多く手軽。テリジノ Lv69。大量なら高効率。金属の鎌が非常に優秀なので恐竜必須ではない。
ベリー
ナルコ含む		手摘み → パラサウロロフス Lv9 → トリケラ Lv16トリケラ / ステゴ Lv26。ステゴなどの草食恐竜でまとめて採る。ブロント Lv63 / テリジノ Lv69。序盤は麻酔薬用ナルコベリーを優先して確保。
石石の斧で岩を叩く。金属の斧 → ドエディクルス Lv34ドエディクルス。石重量75%軽減 + 自動採取。ドエディ + アルゲン Lv62で運搬。斧系はピッケルより石寄り。
火打石石のピッケル。金属のピッケル Lv20。アンキロ Lv36。アンキロ + アルゲン。ピッケル系は斧より火打石寄り。
金属鉱石必要最低限だけ石のピッケル。金属のピッケル Lv20。コリンソス東の鉱脈を使う。アンキロ Lv36。金属重量85%軽減。アンキロ + アルゲン Lv62で遠征。Astraeosではコリンソス東 47/24付近の低地が序盤向け。
水晶石ピッケルでも可能だが効率が低い。金属のピッケル。アンキロ。アンキロ + アルゲン。Astraeosでは山頂付近の薄紫色の水晶を狙う。
黒曜石本格的に集めるのは後回し。金属のピッケル。アンキロ。アンキロ + アルゲン。高地・山岳の黒く光る鉱石。金属採掘遠征とまとめやすい。
キチン / ケラチンカルボネミスを弓で倒して斧で剥ぐ。海岸の三葉虫も狙う。同じルートを金属の斧で高速化。メガテリウム Lv52 + 虫洞窟。メガテリウム / テリジノ Lv69。三葉虫はキチンに加え、原油・シリカ真珠・黒真珠も狙える。
セメントすり鉢でキチン/ケラチン + 石から作る。同じ。必要量が少ないうちはクラフトで十分。ビーバーダムを見つけたら回収。カエルで虫狩りも候補。ビーバーダム / ベールゼブフォ / アフリカマイマイのペースト。Astraeosではフォキントス 5.7/7.3付近の巨大ビーバーダムが候補。
原油コリンソス東の海岸で打ち上げられたメガロドンの死体を見つけたら回収。金属のピッケルで原油岩を採掘。アンキロで原油岩。海に出るなら水中採掘へ。ダンクルオステウスなどで大量採掘 / 油田利用。三葉虫からも少量。フォキントスには原油ポンプを置ける油田がある。
シリカ真珠海岸の三葉虫を見つけたら回収。浅瀬・水中の貝を手で拾う。安全な水中移動手段を用意して採取範囲を広げる。アングラーなど水中採取生物を使う。貝は道具不要で手拾い。ビーバーダムにも入ることがある。
皮序盤の生物を倒して斧で剥ぎ取る。海岸のメガロドン死体も便利。金属の斧で効率化。戦闘用肉食恐竜で狩りながら回収。大量狩り + 高品質ツール / 採取恐竜。ピッケルより斧のほうが皮寄り。
