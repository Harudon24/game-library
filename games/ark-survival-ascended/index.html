素材集めロードマップ

レベル帯ごとのおすすめ
Lv1–19
手作業 → 最初の採取恐竜
  • 石の斧 / 石のピッケルを素材によって使い分ける。
  • モスコプスはサドル不要。繊維・ベリーなどの序盤万能枠。
  • パラサウロロフスはLv9、トリケラトプスはLv16から騎乗可能。ベリー集めを楽にする。
Lv20–35
金属ツール + 専門恐竜が始まる
  • Lv20で金属のピッケル。手掘りの金属・水晶・黒曜石が大きく改善。
  • ステゴサウルス Lv26、金属の鎌 Lv30。
  • マンモス Lv31で木材が一気に楽になる。
  • ドエディクルス Lv34で石集めを専門化。
Lv36–60
鉱石と洞窟素材を効率化
  • アンキロサウルス Lv36で金属・火打石・水晶・黒曜石をまとめて担当。
  • メガテリウム Lv52で虫狩り。洞窟のキチン集めが大幅に楽になる。
  • この帯ではマンモス・ドエディ・アンキロの3匹が素材集めの中心。
Lv61+
大量採取 + 運搬を完成
  • カストロイデス Lv61：木材採取 + 木材/石/わら/繊維の重量50%軽減。
  • アルゲンタヴィス Lv62：採取恐竜を運び、遠征効率を大きく改善。
  • ブロントサウルス Lv63：ベリー・わらを大量採取。
  • テリジノサウルス Lv69：木材・繊維・キチンなどの高効率な万能採取。
レベル表記は主にサドル解放レベル。 テイム自体はそれ以前でも可能。モスコプスはサドル不要なので、序盤からそのまま使える。

MOD 運用メモ

便利にはするが、ARK本来の進行は残す構成

Visual Storage

導入中
  • Wireless Craftingで、近くのVSストレージ内素材をクラフトに直接利用できる。
  • VSかまどに燃料用の木材を入れていると、建築材料として使われる場合がある。
  • 現在の運用ではかまど近くに木材用VSストレージを置き、そちらを材料側に使わせる。
  • 将来的に工業炉を使う段階ではガソリン燃料になるため、木材問題の影響は小さくなる。
  • VSの個数が一時的に5倍表示されたことがあるが、実際の個数は増えておらず再入場で解消。ローカルの ItemStackSizeMultiplier=1 も確認済み。

Upgrade Station

導入中 · Ghazlawl
  • Upgrade Stationを設置し、強化したい武器・防具・道具・サドルを中へ入れる。
  • 対象を選び、必要素材を入れて ATTEMPT UPGRADE。
  • 不要な装備はSalvageで分解して素材の一部を回収できる。
  • 最初は不要な低品質装備で操作を試すと分かりやすい。

Configurable Cryopods

導入予定

菜園

作物の収穫方法

「収穫期」になったら、作物は菜園インベントリに自動で増える

収穫ボタンを押す方式ではない。菜園を開いて、中に生成されたベリーや野菜を自分のインベントリへ移せば収穫完了。

水・肥料・植えた種が維持されていれば、収穫後もそのまま次の作物が増えていく。

水 + 肥料 + 種→成長→収穫期→菜園内に作物が自動生成

覚えておくこと

プレイ中の判断用
採取道具の基本木・皮・石を多めに欲しいときは斧寄り。わら・肉・火打石・鉱石類はピッケル寄り。
採取恐竜の優先マンモス → ドエディクルス → アンキロサウルスまで揃うと、主要建築素材の採取が一気に楽になる。
運搬の次の大きな改善Lv62のアルゲンタヴィス。アンキロやドエディなどの採取遠征と相性が良い。
キチンの段階序盤はカルボネミス / 三葉虫、中盤はメガテリウムで洞窟の虫へ。
